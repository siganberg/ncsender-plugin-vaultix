Update ncSender first

Vaultix Sync needs a newer ncSender than the one running here. Update ncSender, then open this again.

Use the Vaultix app on this computer

This plugin is for ncSender kiosks. On a desktop, the Vaultix app syncs faster and keeps working when ncSender is closed.

1 · Install VaultixGet the app for macOS, Windows or Linux. The same page has the server, if you don't run one yet: github.com/siganberg/vaultix/releases/latest
2 · Point it at your ncSender files When the app asks which folder to sync, choose this one. Your Vaultix files then show up in the ncSender file manager.

Sign in to your Vaultix

Use the same address and account as the Vaultix web app.

The password is used once to register this kiosk, then forgotten. No Vaultix server yet? It's a free cloud drive you run yourself. Download and setup steps: github.com/siganberg/vaultix

Enter your 6-digit code

Open your authenticator app and type the code for Vaultix.

Which folder should sync?

G-code files in the folder you pick appear under Vaultix in the ncSender file manager.

Only G-code files sync (.nc, .gcode, .gc, .g, .gco, .ngc, .ncc, .tap, .cnc).
